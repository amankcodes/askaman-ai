# AskAman AI

AI-powered interactive portfolio and professional AI representative.

- Built with Java and Spring Boot.
- Integrates Google Gemini API for natural-language conversations.
- Provides recruiter-focused information about Aman.
- Covers skills, experience, projects, and professional background.
- Supports direct contact and recruiter inquiries.
- Includes email notification functionality for contact requests.
- Responsive, minimal, and modern chat-based UI.
- Designed for smooth conversational interaction.
- Uses environment variables for sensitive API credentials.
- Built as a practical demonstration of AI + backend integration.
